# Alena - Belarusian Offline TTS

**Alena** - нейросетевая модель для синтеза белорусской речи, работающая полностью локально, без подключения к интернету.

Модель создана на основе **Piper (VITS)** и предназначена для преобразования белорусского текста в аудиозапись. Её можно использовать для экспериментов с синтезом речи, озвучивания текста и разработки собственных приложений.

Основная цель проекта - получить женский белорусский голос с естественным звучанием и возможностью управлять произношением слов.

## О модели

- **Язык:** белорусский (`be`)
- **Тип голоса:** женский
- **Архитектура:** VITS / Piper
- **Частота дискретизации:** 22 050 Гц
- **Формат модели:** ONNX
- **Выбранная версия:** Alena Stress, epoch 859
- **Работа:** полностью офлайн

Модель обучалась на подготовленной части белорусского корпуса Mozilla Common Voice 27.0. Для обучения были отобраны записи одного диктора: 3793 записи для обучения и валидации и 200 для тестирования.

## Быстрый запуск

Для обычного синтеза речи не нужна видеокарта NVIDIA или установленный PyTorch. Достаточно Python и Piper.

**1. Установите Python и создайте окружение:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

**2. Установите Piper:**

```bash
python -m pip install --upgrade pip
python -m pip install piper-tts
```

**3. Скачайте модель.**

Скачайте файлы из раздела Releases:

- `alena_stress_epoch859.onnx`
- `alena_stress_epoch859.onnx.json`

Поместите оба файла в папку `models/`. Они должны находиться рядом.

**4. Создайте первую аудиозапись:**

```bash
python -m piper \
  -m models/alena_stress_epoch859.onnx \
  -f output.wav \
  -- "Добры дзень! Як вашы справы?"
```

Результат сохранится в `output.wav`.

## Примеры генерации

Обычный текст:

```bash
python -m piper \
  -m models/alena_stress_epoch859.onnx \
  -f example1.wav \
  -- "Сёння вельмі прыгожае надвор'е."
```

Более длинное предложение:

```bash
python -m piper \
  -m models/alena_stress_epoch859.onnx \
  -f example2.wav \
  -- "Беларуская мова вельмі прыгожая, і я хачу, каб яна гучала часцей."
```

Настройка скорости и вариативности произношения:

```bash
python -m piper \
  -m models/alena_stress_epoch859.onnx \
  --length-scale 1.0 \
  --noise-scale 0.667 \
  --noise-w-scale 0.8 \
  -f example3.wav \
  -- "Вітаю вас!"
```

`length_scale` управляет скоростью речи: большее значение делает речь медленнее. Параметры `noise_scale` и `noise_w_scale` влияют на вариативность синтеза.

## Как управлять ударениями

В белорусском языке встречаются слова, у которых ударение зависит от значения и контекста. Автоматический фонетизатор eSpeak не всегда правильно определяет нужный вариант.

**Важно:** добавление знака ударения непосредственно в написание слова не гарантирует, что Piper его учтёт.

Для более точного управления можно передавать модели фонемы IPA с помощью конструкции `[[...]]`. Символ `ˈ` обозначает основное ударение.

Например, для слова **дамы**:

```bash
python -m piper \
  -m models/alena_stress_epoch859.onnx \
  -f stress_example.wav \
  -- "У пустыя [[damˈɨ]] часта прыходзяць бяздомныя."
```

Ещё один пример - слово **пару**:

```bash
python -m piper \
  -m models/alena_stress_epoch859.onnx \
  -f stress_example2.wav \
  -- "У халодную [[parˈu]] года."
```

В этих примерах фонемы заданы вручную, поэтому Piper не пытается заново определить произношение соответствующего слова.

## Обучение собственной модели

Если вы хотите не просто использовать Алёну, а обучить собственный голос, потребуется больше зависимостей и подготовленный аудиодатасет.

Для обучения рекомендуется компьютер с видеокартой NVIDIA и поддержкой CUDA.

**1. Установите системные зависимости (Ubuntu):**

```bash
sudo apt update
sudo apt install -y \
  git build-essential cmake ninja-build \
  python3-dev python3-venv
```

**2. Скачайте исходный код Piper:**

```bash
git clone https://github.com/OHF-Voice/piper1-gpl.git
cd piper1-gpl
```

**3. Подготовьте Python-окружение:**

```bash
python3 -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip
python -m pip install -e ".[train]"
```

**4. Соберите необходимые расширения:**

```bash
./build_monotonic_align.sh
python setup.py build_ext --inplace
```

Для обучения на GPU также необходимо установить подходящую версию PyTorch с поддержкой CUDA. Версию следует выбирать с учётом видеокарты и драйвера NVIDIA.

### Подготовка данных

Piper использует аудиофайлы и CSV-файл с соответствующими текстами. Например:

```text
0001.wav|Добры дзень!
0002.wav|Сёння добрае надвор'е.
0003.wav|Вітаю вас!
```

Для белорусского языка указывается код фонетизации `be`.

Обучение можно начинать с существующего checkpoint, что обычно позволяет быстрее получить пригодный голос по сравнению с обучением с нуля.

Официальная инструкция: [Piper Training](https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/TRAINING.md).

**Примечание:** для получения именно Alena 859 использовался отдельный сценарий дообучения с исправленными IPA-фонемами и сохранённой картой фонемных ID. Подробную конфигурацию этого эксперимента необходимо использовать вместе с соответствующими обучающими скриптами; обычная команда Piper сама по себе не воспроизводит полученные веса.

## Как обучалась Alena

В качестве отправной точки использовался предварительно обученный checkpoint:

[Rhasspy Piper — base_model](https://huggingface.co/datasets/rhasspy/piper-checkpoints/tree/main/_base_model)

Далее модель дообучалась на белорусских аудиозаписях.

Обучение проводилось на следующем компьютере:

- **ОС:** Ubuntu 26.04.1 LTS
- **Процессор:** AMD Ryzen 9 9950X
- **Оперативная память:** 64 ГБ
- **Видеокарта:** NVIDIA GeForce RTX 5070 Ti, 16 ГБ
- **Python:** 3.12
- **PyTorch:** 2.9.0

В ходе экспериментов сравнивались различные checkpoint. После дополнительного обучения на исправленных фонемах была выбрана модель эпохи 859 (`val_mel = 0.4802`).

При прослушивании тестовых фраз этот вариант показался наиболее удачным. При этом отдельные слова всё ещё требуют коррекции ударений.
